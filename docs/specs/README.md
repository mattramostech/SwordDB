# Specifications

This directory is the source of truth for all project decisions and business rules, including architectural choices, technical decisions, and expected database behavior.

Record decisions and business rules here before implementing them. Explain the decision, its rationale, and the expected behavior, and keep specifications current as the project evolves.

Roadmap entries and agent instructions should link to the relevant specifications when referring to project decisions or business rules.
