# AI Usage and Human Responsibility

## Decision

AI agents may be used to contribute to SwordDB. All code must be validated and approved by a human engineer who takes responsibility for it, regardless of whether AI was used.

## Rationale

Only humans can be accountable for generated code. Using an AI agent does not transfer responsibility away from the engineer contributing or approving that code.

## Contribution acceptance

No contribution will be accepted without validation and approval by a responsible human engineer.
